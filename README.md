# SalesRank.AI – AI-Powered Sales Coach Website

Welcome to the repository for **SalesRank.AI**, an advanced AI-powered web application designed to help users improve their sales strategies with real-time coaching, data analysis, and intelligent suggestions.

This modern frontend application is built using **Next.js** and styled with **Tailwind CSS**, offering a fast, responsive, and elegant experience across devices.

## Features

- Modern, responsive UI built with Next.js and Tailwind CSS
- AI Coach chatbot interface
- Course section with detailed info cards
- FAQ accordion section
- Smooth navigation with a sticky navbar and mobile menu
- Swiper-based testimonial and course sliders
- Countdown component for upcoming features or launches

## 🔧 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
- **Carousel:** [Swiper.js](https://swiperjs.com/react)
- **Countdown Timer:** [React Countdown](https://www.npmjs.com/package/react-countdown)
- **FAQ Section:** [react-faq-component](https://www.npmjs.com/package/react-faq-component)

## 📦 Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/masud040/salesRank.git
cd salesrank-ai
npm install --force
npm run dev
```
